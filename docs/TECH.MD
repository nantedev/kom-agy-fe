# Stack technique

## Frontend

- **Framework** : React
- **Build tool** : Vite
- **Langage** : TypeScript
- **Styling** : Tailwind CSS (v4)
- **Composants UI** : shadcn/ui
- **Icônes** : Lucide React
- **Gestion d'état / requêtes** : TanStack Query
- **Tests** : Vitest / React Testing Library / Playwright

## Infrastructure & Outillage

- **Hébergement frontend** : Vercel
- **Hébergement backend** : Render
- **Hébergement base de données** : Neon
- **Versioning & CI/CD** : GitHub / GitHub Actions
- **Gestion de projet & documentation** : Notion
